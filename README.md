# Linux

## Шаг 1: Как установить программу

Запомни одну команду-поисковик:

```bash
# УЗНАТЬ КОМАНДУ ДЛЯ УСТАНОВКИ (работает в Ubuntu/Debian/Mint)
apt search ключевое_слово
```

Примеры:
```bash
apt search btop        # покажет, что пакет называется btop
apt search system      # системные утилиты
```

## Шаг 2: Самое простое решение 

Установи **одну программу** `bpytop` — это почти как микротиковский мониторинг:

```bash
# Открой терминал (Ctrl+Alt+T) и введи эти 3 команды по очереди:
sudo apt update
sudo apt install bpytop
bpytop
```

Всё! Откроется красивый мониторинг:
- CPU, память, диски
- Сеть, кто сколько качает
- Процессы

Клавиши для управления:
- `1` `2` `3` `4` — переключение вкладок
- `q` — выход

## Шаг 3: Если bpytop не нашёлся

Пробуй другие, они почти одинаковые:
```bash
sudo apt install btop     # новее
sudo apt install htop     # проще, только процессы
sudo apt install glances  # тоже красиво
```

## Шаг 4: Как теперь искать ЛЮБУЮ программу

Твоя шпаргалка на будущее:

```bash
# 1. Сначала ищешь, есть ли такая программа
apt search что_ищешь

# 2. Устанавливаешь
sudo apt install название_пакета

# 3. Запускаешь
название_пакета
```

Пример поиска сетевых программ:
```bash
apt search network monitor    # найдёт всё связанное с "network" и "monitor"
```
